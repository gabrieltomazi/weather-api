## 📝 Sobre o Projeto

O **Weather API** é uma aplicação web simples e funcional que permite aos usuários consultar informações climáticas de qualquer cidade do mundo em tempo real. O projeto foi desenvolvido para praticar a manipulação de **DOM**, consumo de **APIs REST** e estilização responsiva.

A aplicação consome dados da [OpenWeatherMap API](https://openweathermap.org/api) para exibir:
* Temperatura atual.
* Condição climática (Sol, Chuva, Nuvens, etc).
* Umidade do ar.
* Velocidade do vento.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização moderna com foco em experiência do usuário.
* **JavaScript (ES6+):** Lógica de consumo da API, tratamento de promessas (Async/Await) e atualização dinâmica da interface.
